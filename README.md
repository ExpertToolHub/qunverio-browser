# Qunverio Browser

Native Android browser (Kotlin, Jetpack Compose, Android System WebView).

## v0.2.0
Tabs, settings, ad/tracker blocking (EasyList host rules), bookmarks, history.
Not yet: downloads, private browsing, permission prompts, file upload, fullscreen video.

## Build (cloud)
Upload a project zip to the repo root -> Actions "Unzip and build" -> artifact `qunverio-debug-apk`.

## Debug vs release
Debug APKs are for testing only. Release signing is not configured yet. Never commit keystores or passwords.
